# Code of Conduct

The Optics Framework Code of Conduct lives in a single place so it cannot drift: [`CODE_OF_CONDUCT.md`](https://github.com/mozarkai/optics-framework/blob/main/CODE_OF_CONDUCT.md) at the repository root.

It applies to everyone participating in the project, across issues, pull requests, discussions, and any other project space. Report unacceptable behaviour to the maintainers at [lalit@mozark.ai](mailto:lalit@mozark.ai), as described in the [Enforcement section](https://github.com/mozarkai/optics-framework/blob/main/CODE_OF_CONDUCT.md#enforcement).
