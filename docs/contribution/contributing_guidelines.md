# Contributing Guidelines

The contribution guide lives in a single place so it cannot drift:
[`CONTRIBUTING.md`](https://github.com/mozarkai/optics-framework/blob/main/CONTRIBUTING.md)
at the repository root.

It covers ways to contribute, development setup, a tour of the project layout,
step-by-step recipes (adding a keyword, adding an engine backend), commit
conventions, and the pull-request format reviewers expect. Tooling depth —
pre-commit hooks, MkDocs previews, local static analysis — stays in the
[Developer Guide](developer_guide.md).
