1134Values from the JSON object are used as they are: Optics does not expand references or resolve paths in them. If the value is not a JSON object, the run stops and names the variable, but does not show its value. Do not use `$from` in the Playwright `capabilities.headers`: the driver expands that map when it connects, so give each header on its own line.

1136Optics writes `****` in place of secrets in the console, the log files, `logs.json`, `junit_output.xml` and error messages. A text value in the config file is a secret when the environment variable or the key that holds it has a word such as `token`, `password`, `pwd`, `pin`, `secret`, `key`, `auth`, `bearer` or `credential` in its name (`HUB_TOKEN`, `appium:keystorePassword`). A key that ends in `_env`, such as `api_key_env`, holds the name of a variable, not a secret. The Python SDK and the `optics serve` and `optics mcp` sessions read no config file, so Optics masks these values where it logs their config. Passwords in URLs (`https://user:****@host`) and query parameters with such names (`?token=****`) are masked wherever they appear.
