332=== "AI Self-Healing"
333
334 ### `ai_self_heal`
335
336 **Type:** `bool` | **Default:** `false`
337
338 Last-resort recovery for element location. When every locator strategy (XPath, text,
339 OCR, image) fails for a self-healing-capable keyword (e.g. `Press Element`, `Enter Text`),
340 a bounded LLM-driven loop reads the screen and attempts to recover before the keyword
341 fails outright.
342
343 Opt-in and inert unless an entry under `llm_models` is also enabled — a missing or
344 misconfigured LLM degrades this to a no-op rather than a failure:
345
346 ```yaml
347 ai_self_heal: true
348
349 llm_models:
350 - gemini:
351 enabled: true
352 ```
353
354 See [LLM Models](#llm-models) below for backend configuration.

807## LLM Models
808
809LLM backends power two opt-in features: the [`ai_self_heal`](#ai_self_heal) recovery path
810above, and `optics live`'s natural-language mode (`Ctrl-N`). Both stay inert until an entry
811below is enabled — the backend SDK is only imported when its engine is enabled, so leaving
812this section out has no cost for projects that don't use either feature.
813
814=== "Gemini"
815
816 **Purpose:** Google Gemini via the `google-genai` SDK, supporting both the Gemini
817 Developer API and Vertex AI. Requires the optional `llm` extra:
818 `pip install 'optics-framework[llm]'`.
819
820 ```yaml
821 llm_models:
822 - gemini:
823 enabled: true
824 capabilities:
825 model: gemini-3.8-flash # optional; framework default is gemini-2.5-flash
826 temperature: 0.0 # optional; this is the default
827 # use_vertexai: true # optional; else uses GOOGLE_GENAI_USE_VERTEXAI
828 # project: your-project # optional Vertex override; else GOOGLE_CLOUD_PROJECT
829 # location: us-east4 # optional Vertex override; else GOOGLE_CLOUD_LOCATION
830 ```
831
832 With no `capabilities` set, the SDK auto-detects everything from environment variables:
833
834 | Variable | Purpose |
835 |----------|---------|
836 | `GEMINI_API_KEY` / `GOOGLE_API_KEY` | Gemini Developer API key |
837 | `GOOGLE_GENAI_USE_VERTEXAI` | Switch to Vertex AI |
838 | `GOOGLE_CLOUD_PROJECT` | Vertex AI project |
839 | `GOOGLE_CLOUD_LOCATION` | Vertex AI location |
840 | `GOOGLE_APPLICATION_CREDENTIALS` | Vertex AI service account credentials |
841
842 !!! warning "Don't hardcode credentials"
843 `capabilities.api_key` / `capabilities.gemini_api_key` are also accepted but log a
844 warning when used — prefer the environment variables above so keys never end up in
845 a committed `config.yaml`.
