856=== "OpenAI-compatible"
857
858 **Purpose:** any server that speaks the OpenAI Chat Completions API, via the `openai`
859 SDK. Without `url` it calls OpenAI; with one it calls that server instead.
860 Install: `pip install 'optics-framework[openai]'`.
861
862 ```yaml
863 llm_models:
864 - openai:
865 enabled: true
866 url: https://openrouter.ai/api/v1 # omit for OpenAI; or OPENAI_BASE_URL
867 capabilities:
868 model: anthropic/claude-sonnet-5-5 # required; the name the server uses
869 api_key_env: OPENROUTER_API_KEY # optional; default OPENAI_API_KEY
870 # response_format: json_object # for servers without JSON-schema output
871 # temperature: 0.0
872 ```
873
874 | Server | `url` | Key |
875 |--------|-------|-----|
876 | OpenAI | (omit) | `OPENAI_API_KEY` |
877 | OpenRouter | `https://openrouter.ai/api/v1` | `OPENROUTER_API_KEY` via `api_key_env` |
878 | Azure OpenAI | `https://<resource>.openai.azure.com/openai/v1/` | your Azure key via `api_key_env` |
879 | Ollama | `http://localhost:11434/v1` | none |
880 | vLLM / LM Studio | the server's `/v1` URL | none |
881
882 Natural-language mode and self-heal send screenshots, so pick a model that accepts
883 images. Responses use strict JSON-schema output by default; if the server rejects it,
884 set `response_format: json_object` and the schema is sent in the prompt instead.

902 # temperature: 0.0
903 ```
