A [airhand](https://github.com/chinmayajha/airhand) dongle in your computer pairs with the device over Bluetooth as a keyboard, mouse and media remote. The driver acts on positions and keys. 638 `Launch App` and `Launch Other App` open the app through the system search: give the name that the search shows, for example `Settings`. On iOS, the driver first presses Home twice, because Home from an app that Spotlight opened goes back to Spotlight. On Android, the driver opens the app drawer with the Meta key instead. Without `app_search`, it types the name and presses Enter, which opens the top result on launchers that filter as you type. With `app_search`, it taps the search box first and then selects the top result with Up and Enter. On iOS and Android, `Force Terminate App` opens the app, then closes it from the App Switcher (Recents on Android, opened with Meta+Tab), so that the next `Launch App` starts it from its first screen. The App Switcher can keep a card on a slow frame, so when a test needs the first screen, assert it after `Launch App`. `Press Keycode` takes a key name (`enter`, `escape`, `tab`, `f1` to `f24`, the arrows), a combination (`cmd+space`, `ctrl+shift+t`) or a media key (`home`, `back`, `volumeup`, `volumedown`, `mute`, `playpause`, `next`, `previous`, `stop`, `brightnessup`, `brightnessdown`). `search` opens the system search. On a computer, `home` is the Home key.
639
640 The dongle times taps, swipes and typing itself and answers every command. If the device is not connected to the dongle, a keyword waits up to 10 s for it and then stops the run (`E0106`). A swipe or scroll on a touch screen moves at least 0.75 screen heights per second, because iOS takes a slower drag for a tap. Element keywords of the driver (`press_element`, `get_text_element`, …) come from the camera instead.
641
642 With a camera, `Press Element` reads one frame and does not wait. After a step that changes the screen, put `Assert Presence` before it: `Assert Presence` waits for the element. On the iOS home screen, tap an app's icon, not its name: use an image of the icon, give `Press Element` on the name an `offset_y` up to the icon, or use `Launch App`.
643
644 On Android, the dongle acts as a touch screen, so taps and swipes are touches with no pointer on the screen. This needs airhand firmware 0.1.2 or later. On iOS and iPadOS, the driver moves the pointer to the top-right corner after each tap and swipe, so that the pointer does not cover the next element in the camera image. This needs airhand firmware 0.1.1 or later.
645
646 **Tips for iOS:** set the hardware keyboard layout to U.S. (Settings > General > Keyboard > Hardware Keyboard), and turn off Auto-Capitalization and Smart Punctuation, so that typed text arrives as sent. Do not press `home` just before `Launch App`: Home a few seconds after an app opened from Spotlight shows Spotlight again, and Cmd+Space then closes it.
647
648 #### Without a camera
649
650 With `elements_sources: []`, a project drives the device by positions and keys only: `Press By Percentage`, `Press By Coordinates`, `Swipe`, `Scroll`, `Enter Text Using Keyboard`, `Press Keycode`, `Clear Text` and `Launch App`. A keyword that must see the screen, such as `Press Element` or `Assert Presence`, stops with `E0501`. No screenshots are saved.
651
652 #### MCP and `optics serve`
653
654 Start a session with `driver="ble"` and the `platform` and `frame` capabilities. When the server has `WEBCAM_SCREENSHOT_URL` set, the session reads the screen through that camera at the frame size; otherwise it runs without a camera. A remote session names the dongle by `serial`, never by `port`, and reads only the camera the server sets: a `url` on `camera_screenshot` is refused, because the server would fetch any address the caller names.
655
656 #### Migrating from the v1 ble driver
657
658 The driver needs airhand firmware. A dongle with other firmware stops the session with a request to flash it.
659
660 | v1 capability | Now |
661 |---------------|-----|
662 | `port` as the USB product name | `serial`, the USB serial number, or nothing with one dongle |
663 | `pixel_width`, `pixel_height` | `frame: {width, height}` |
664 | `mickeys_width`, `mickeys_height`, `x_invert`, `y_invert` | Remove them. Positions go to the dongle as fractions of the frame, so no calibration is necessary. |
