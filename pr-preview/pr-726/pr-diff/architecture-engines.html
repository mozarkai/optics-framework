112112
n113**Location:** `optics_framework/engines/drivers/ble.py`n113**Location:** `optics_framework/engines/drivers/ble.py`, on the [airhand](https://github.com/chinmayajha/airhand) client
114114
n115The BLE (Bluetooth Low Energy) driver provides non-intrusive automation for production devices.n115The driver drives a device that has nothing installed: a phone, a tablet, a computer or a TV. An airhand dongle pairs with the device over Bluetooth as a keyboard, mouse and media remote. The airhand client sends it one command per line over USB serial.
116116
n117#### Key Featuresn117- Positions go to the dongle as fractions of `frame`, so devices need no calibration.
118- The dongle times taps, swipes and typing. The driver does not sleep between reports.
119- A lost reply is asked for again with `result <id>`. An action is never sent two times.
120- `platform` selects the shortcuts: select-all, Back, the system search for `Launch App`, and a drag or the wheel for `Scroll`.
121- airhand errors map to Optics codes: a lost dongle or a device that stays disconnected for 10 s is `E0106` (the run stops; element fallback does not try again), other firmware is `E0501`, and input the dongle cannot send is `E0403`.
118122
t119- Non-intrusive mouse and keyboard controlt123Element methods are not supported. Elements come from `camera_screenshot` and the OCR and image strategies. See [Configuration](../configuration.md) for the capabilities.
120- Serial communication via BLE
121- Coordinate mapping (pixels to mickeys)

148#### Key Methods

156#### Coordinate Mapping
157
158The BLE driver maps screen coordinates to mouse movements (mickeys):
159- Pixel coordinates → Mickey coordinates
160- Supports coordinate inversion
161- Configurable mapping ratios
