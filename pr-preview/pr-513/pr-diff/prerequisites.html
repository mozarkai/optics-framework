21### Linux: OpenCV needs a system OpenGL library
22
23Optics depends on `opencv-python`, which links against `libGL`. Minimal Linux images — Docker containers, CI runners, cloud dev environments — usually don't ship it, so `optics --version` fails on import with `ImportError: libGL.so.1: cannot open shared object file`. Install the library from your distro:
24
25```bash
26sudo apt-get install -y libgl1 # Debian/Ubuntu
27sudo dnf install -y mesa-libGL # Fedora/RHEL
28sudo pacman -S libglvnd # Arch
29```
30
31Desktop Linux installs normally already have it. macOS and Windows are unaffected.
