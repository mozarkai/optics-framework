357=== "Natural-Language Agent"
358
359 ### `nl_agent`
360
361 **Type:** `object` | **Default:** `{vision: auto, max_steps: 15, escalation_model: ""}`
362
363 Settings of the natural-language mode of `optics live` (`Ctrl-N`). They have an effect
364 only when an entry under `llm_models` is enabled.
365
366 | Key | Meaning |
367 |-----|---------|
368 | `vision` | When the agent sends the screenshot. `auto` sends it on the first turn, after a step that code did not confirm, when the screen has few or unlabelled controls, and when no element list is available. `always` sends it on every turn. `never` sends no image, for text-only models. |
369 | `max_steps` | The most actions the agent takes for one instruction. |
370 | `escalation_model` | A model ID for the same engine as the first enabled `llm_models` entry. The agent sends hard turns to it: a second try after a bad reply, a turn after two failures in a row, and a turn with a guard note. Empty means one model for all turns. |

nn427 !!! info "Idle wait before each command"
428 Before each command, UiAutomator2 (Android) and XCUITest (iOS) wait for the app to
429 stop changing. Their own limit is 10 seconds, so on a screen that never stops
430 changing (a running timer, a focused input) every step takes 10 seconds or more.
431 Optics sets the limit to 1 second. Your `appium:settings` merge with this default.
432 To change the limit, set `waitForIdleTimeout`: Android takes milliseconds, iOS
433 takes seconds, and `0` disables the wait on both:
434
435 ```yaml
436 capabilities:
437 appium:settings:
438 waitForIdleTimeout: 0
439 ```
