357=== "Natural-Language Agent"
358
359 ### `nl_agent`
360
361 **Type:** `object` | **Default:** `{vision: auto, max_steps: 15, escalation_model: ""}`
362
363 Settings of the natural-language mode of `optics live` (`Ctrl-N`). They have an effect
364 only when an entry under `llm_models` is enabled.
365
366 ```yaml
367 nl_agent:
368 vision: auto # auto | always | never
369 max_steps: 15
370 escalation_model: "" # optional; a stronger model of the first enabled engine
371 ```
372
373 | Key | Meaning |
374 |-----|---------|
375 | `vision` | When the agent sends the screenshot. `auto` sends it on the first turn, after a step that code did not confirm, when the screen has few or unlabelled controls, and when no element list is available. `always` sends it on every turn. `never` sends no image, for text-only models. |
376 | `max_steps` | The most actions the agent takes for one instruction. |
377 | `escalation_model` | A model ID for the same engine as the first enabled `llm_models` entry. The agent sends hard turns to it: a second try after a bad reply, a turn after two failures in a row, and a turn with a guard note. Empty means one model for all turns. |
