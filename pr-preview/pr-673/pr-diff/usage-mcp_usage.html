203### What an action returns
204
205```
206tap e7 "Sign in" -> ok (XPath) · verified: pass
207check present "Welcome": met
208screen 4436bc · changed (+2 -0 ~0)
209+ e8 p "Welcome, a@b.c"
210+ e9 a "Orders" [tap]
211```
212
213- The first line gives the target, the keyword result with the locator
214 strategy that found it, and the verdict.
215- One line follows for each expectation.
216- The screen line is `unchanged`, `changed` with the added (`+`), removed
217 (`-`) and relabelled (`~`) rows, or `new screen` with every row. Pass
218 `screen="full"` for every row, or `screen="none"` for no screen line.
219- A ref never moves to a different element. A ref that is gone from the
220 screen is an error that lists the current rows.
221
222The verdict rule:
223
224| Result | `verified` |
225|--------|------------|
226| the keyword failed | `fail` |
227| no expectations | `unknown` |
228| every expectation met, and the screen changed or an `expect_present` that was not met before is met now | `pass` |
229| an expectation not met, and the screen did not change | `fail` |
230| an expectation not met, but the screen changed | `unknown` (the unmet checks are listed) |
231| the screen could not be read after the action | `unknown`; the expectations are not checked |
232
233Each acting tool also returns `structuredContent`:
234
235```json
236{"ok": true, "verified": "pass", "verb": "tap", "keyword": "press_element",
237 "target": {"ref": "e7", "label": "Sign in", "ladder": ["xpath=//button[normalize-space()='Sign in']"], "strategy": "XPath"},
238 "checks": [{"text": "Welcome", "expect": "present", "met": true}],
239 "screen": {"digest": "4436bc", "changed": true, "new_screen": false,
240 "added": [{"ref": "e8", "label": "Welcome, a@b.c", "cls": "p", "act": []}],
241 "removed": [], "relabelled": []}}
242```

427### Full toolset (`--toolset full`)
428
429The full toolset keeps the earlier surface for clients that call keywords by
430name: one string-typed tool per keyword of `ActionKeyword`, `AppManagement`
431and `Verifier` (each takes `session_id` and the keyword's params as strings),
432the `screenshot` tool, and the core `start_session`, `terminate_session`,
433`observe`, `tap`, `type_text`, `press_key`, `check` and `run_keyword`. The
434keyword tools `scroll` and `launch_app` replace the core tools with the same
435names. An element param of a keyword tool also accepts a ref from the latest
436`observe`.
