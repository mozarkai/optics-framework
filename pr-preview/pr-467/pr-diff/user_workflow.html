13- **--name**: Specifies the project name (required).
14- **--path**: Directory where the project folder is created (default: current directory).
15- **--template**: (Optional) Copy a complete sample project (`contact`, `clock`, `calendar`, `youtube`, `gmail_web`, `playwright`).
16
17With `--template`, the project is a ready-to-run copy of that sample. Without it, `optics init` scaffolds the subdirectory layout (`test_cases/`, `modules/`, `test_data/`) plus a commented starter `config.yaml` for you to fill in.
