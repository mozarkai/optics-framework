nn64**Preflight check:** before running anything, `optics execute` verifies the enabled driver's backend is actually reachable — the Appium server (plus at least one attached Android device via `adb`) for Appium projects, or the remote WebDriver URL for Selenium projects. 211## Checking Your Setup
212
213Diagnose engines, tooling, and a project's `config.yaml`:
214
215```bash
216optics doctor [folder] [--check]
217```
218
219- `[folder]`: Project folder to diagnose (default: current directory). With one, the Appium probe targets that project's configured server URL and its `config.yaml` is validated.
220- `--check`: Non-interactive mode — exit non-zero when a project-config check fails (useful in CI).
