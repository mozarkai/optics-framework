10We welcome contributions in the form of bug reports, feature requests, documentation improvements, and code contributions. To contribute, follow these steps:11[Developer Guide](developer_guide.md).
11
12- **Fork the Repository:** Click the "Fork" button on the top right of the repository page to create a copy of the repository in your GitHub account.
13
14- **Clone the Repository:** Clone the forked repository to your local machine using the following command:
15
16```bash
17git clone <your_forked_repository_url>
18```
19
20- **Create a Branch:** Create a new branch for your contribution using the following command:
21
22```bash
23git checkout -b <branch_name>
24```
25
26- **Make Changes:** Make your changes to the codebase, documentation, or tests.
27
28- **Commit Changes:** Commit your changes with a descriptive commit message.
29
30!!! tip "Commit Message Format"
31 Ensure that your commit messages follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) format for consistency and clarity (e.g., `feat: add new feature`, `fix: resolve bug #123`).
32!!! note "Signing Commits"
33 Sign your commits using the [Developer Certificate of Origin (DCO)](https://developercertificate.org/) to certify your contribution. Use `git commit -s` to add a `Signed-off-by` line.
34
35
36- **Push Changes:** Push your changes to your forked remote repository.
37
38- **Create a Pull Request:** Create a pull request from your forked repository to the main repository.
39
40!!! tip "Referencing Issues in Pull Requests"
41 If you are fixing an issue, reference the issue number in your pull request message using the format `Fixes #<issue_number>` to link it automatically.
42
43- **Review and Merge:** The maintainers will review your pull request and merge it if it meets the project's guidelines.
44
45## Reporting Issues
46
47To report a bug, follow these steps:
48
491. **Check Existing Issues:** Check if the bug has already been reported by searching the existing issues.
50
512. **Create a New Issue:** If the bug has not been reported, create a new issue with the following details:
52
533. **Issue Title:** A descriptive title that summarizes the bug.
54
554. **Description:** A detailed description of the bug, including steps to reproduce it.
56
575. **Expected Behavior:** A description of what you expected to happen.
58
596. **Actual Behavior:** A description of what actually happened.
60
617. **Environment:** Details about your environment, such as the operating system, Python version, and any other relevant information.
62
638. **Screenshots:** If applicable, include screenshots that help illustrate the bug.
64
659. **Labels:** Add appropriate labels to the issue, such as `bug` or `enhancement`.
