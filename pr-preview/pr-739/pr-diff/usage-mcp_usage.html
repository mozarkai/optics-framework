515### Feedback and update notices
516
517`send_feedback` posts the report, the client name, the Optics version, the
518transport and the operating system to `https://optics-framework.org/api/feedback`.
519Before it sends, it masks the session's secret values, keys, tokens and email
520addresses. To remove the tool, set `OPTICS_NO_FEEDBACK=1`.
521
522The server checks PyPI for a newer Optics once a day. When one is out, the
523first `start_session` reply tells the agent to tell you. To stop the check,
524set `OPTICS_NO_UPDATE_CHECK=1`. `DO_NOT_TRACK=1` stops both.
