83### Running selected test cases
84
85Pick test cases by name without editing `config.yaml`:
86
87```bash
88optics execute ./my_project --include "Login Test"
89optics execute ./my_project --include "Login Test" "Checkout Test"
90optics execute ./my_project --exclude "Slow Test" --exclude "Flaky Test"
91optics dry_run ./my_project --include "Login Test"
92```
93
94- **Whole names, any case.** A name must match a full test case name. Case and extra spaces are ignored (`"login TEST"` matches `Login Test`), but there is no prefix, substring or wildcard matching.
95- **Several names.** List them after one flag, repeat the flag, or both. Quote names that contain spaces.
96- **One or the other.** `--include` and `--exclude` cannot be combined.
97- **Overrides `config.yaml`.** Either flag replaces the project's `include`/`exclude` settings for that run. Without the flags, `config.yaml` applies as before.
98- **Setup and teardown always run.** Test cases whose name contains `setup` or `teardown` still wrap the selection. Excluding one prints a note and has no effect.
99- **Order.** Selected test cases run in project order, not in the order you list them.
100- **Folder first.** Put the project folder before `--include`/`--exclude`: every argument after the flag is read as a test case name until the next option.
101
102Before anything runs, the command prints `Selected N of M test cases: …`. It stops with exit code `3` (invalid input) and no session started when:
103
104- a name matches no test case. The error suggests the closest name (`Did you mean 'Checkout Test'?`) and lists the project's test cases.
105- `--exclude` removes every test case, or `--include` names only setup/teardown test cases.
106
107A malformed command line exits with code `2` instead: a blank name, or `--include` and `--exclude` together.
108
109An unknown name in `config.yaml`'s `include`/`exclude` only prints a warning, so existing projects keep running.

111### Listing test cases
112
113`--list` prints the test cases a run would select, one per line, and exits. It starts no session, runs no preflight and needs no enabled driver, so it works before a device is set up.
114
115```bash
116optics execute ./my_project --list # every test case
117optics execute ./my_project --include "Login Test" --list # preview a selection
118```
119
120- The names go to stdout exactly as `--include`/`--exclude` accept them, so they can be piped or pasted back into a command.
121- Selection from `--include`/`--exclude` or `config.yaml` applies. When one is active, `Selected N of M test cases` is printed to stderr.
122- Setup and teardown test cases are listed on stderr as `Always run: …`, since they run around every selection.
123- An unknown name or an empty selection exits with code `3`, the same as a real run.
