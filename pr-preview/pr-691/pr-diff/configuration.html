533 `${NAME}` in `url` or in a header value is replaced with that environment variable when the browser starts, so credentials stay out of the suite. The value is substituted as is, so inside a URL-encoded query write the reference itself unencoded. An unset or empty variable fails the launch with an error that names it. Only the url's host is logged, and secret values and the url's path and query are masked in connect errors. `Close And Terminate App`, or the end of the run, closes the connection, which is what ends the session on the provider's side. 540 **Start signed in with a local profile:** set `profile` to a Chrome or Edge profile on the machine that runs Optics. Optics copies the profile's cookies, local storage and preferences into a new folder, launches the installed browser (`channel`, or the profile's own browser) with the copy, and deletes the copy when the session ends. The profile itself is not changed, and the browser can stay open. `optics mcp` lists the profiles in the `optics://browser-profiles` resource, and a `profile` that matches none fails with `E0501` and lists them. Most site sign-ins carry over, but Google accounts are signed out in a copy. Not with a remote `url` or `storage_state`.
