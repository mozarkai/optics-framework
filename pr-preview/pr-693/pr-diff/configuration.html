n622 Both Tizen and webOS use D-pad buttons (UP/DOWN/ENTER/BACK) for navigation, not touch. Touch-based methods (`click_element`, `swipe`, `enter_text`) raise an error on TVs.n622 A Tizen or webOS app is a web page, so `appium_find_element` finds `text=` (visible text, `aria-label`, `title` or `alt`) and `css=` locators in its DOM. A TV has no touch, so the element keywords move the remote's focus instead:
623
624 - `Press Element` presses arrow keys until the element has focus, then presses ENTER. Focus is read from the page after each key press, so you do not count presses.
625 - `Enter Text` types into a real `<input>` directly. For a field the app draws itself, it walks the app's on-screen keyboard key by key, switches its layers (`123`, `abc`) when a character is not shown, and reads the field after. If the field does not show the text, the step fails with `E0405` and no fallback types it again. A letter case that the app picks itself (a capital first letter) gives only a warning.
626 - `Clear Element Text` presses the keyboard's backspace key until the field stops changing.
627 - `Get Text` reads the element's text or a field's value.
628 - `Enter Text` with `<space>`, `<backspace>` or `<enter>` presses that key of the on-screen keyboard; `<escape>` and the arrows press remote keys.
629 - Use `Assert Presence` to wait for a screen in place of `Sleep`.

t683 - Methods that raise an error on TVs — Touch: `click_element`, `press_element`, `press_coordinates`, `tap_at_coordinates`, `swipe*`; Keyboard: `enter_text`, `clear_text`; Other: `scroll`, `get_text_element`, `press_xpath_using_coordinates`.t690 - Keywords that raise `E0105` on TVs: coordinate taps, swipes, scrolls, `Select Dropdown Option`, the checked state in `Is Element`, typing without an element, and `Go Back` (use `Press Keycode` with `BACK`). `Press Keycode` sends remote keys; an unknown key name fails with `E0104`.
684 - Methods that work everywhere: `launch_app`, `press_keycode`, `execute_script`, `terminate`.691 - Each focus move costs one remote key press (about 1–2 s on a TV), so typing a long text takes time.
685 - Text input isn't supported — use a sequence of `Press Keycode` steps for D-pad navigation through on-screen keyboards.692 - A native screenshot hangs a Tizen TV, so `appium_screenshot` refuses it there: use `camera_screenshot`.
