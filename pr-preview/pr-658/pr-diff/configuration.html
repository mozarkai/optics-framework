709 !!! note "Environment fallback"
710 When neither `url` nor `camera_index` is configured, the source reads
711 `WEBCAM_SCREENSHOT_URL` and `WEBCAM_SCREENSHOT_TOKEN` (HTTP). If no URL is set but
712 `WEBCAM_SCREENSHOT_TCP_PORT` is, it connects over raw TCP to `127.0.0.1:<port>`.
713 `token` falls back to `WEBCAM_SCREENSHOT_TOKEN`. Explicit config always wins over env.
