tt704=== "Desktop (Appium)"
705
706 **Purpose:** Native desktop apps on macOS, Linux and Windows. The `appium-xa11y-driver` reads the accessibility tree of the operating system. Windows support is experimental.
707
708 **Prerequisites:**
709 - **Appium 3** on the machine that shows the app
710 - The driver: `appium driver install --source=npm appium-xa11y-driver`
711 - macOS: give Accessibility and Screen & System Audio Recording to the app that runs Appium (System Settings > Privacy & Security)
712 - Linux: an X11 display, a D-Bus session and the AT-SPI bus
713
714 ```yaml
715 driver_sources:
716 - appium:
717 enabled: true
718 url: "http://127.0.0.1:4723"
719 capabilities:
720 platformName: Mac # or Linux / Windows
721 automationName: Xa11y
722 app: com.apple.TextEdit # .app path or bundle id on macOS, an executable elsewhere
723
724 elements_sources:
725 - appium_find_element:
726 enabled: true
727 - appium_page_source:
728 enabled: true
729 - appium_screenshot:
730 enabled: true
731 ```
732
733 Use `appName` in place of `app` to attach to an app that runs. Locators are XPath over the role tags (`//button[@name="Save"]`), `@id` or visible text. `Press Keycode` takes a chord: `cmd+n` on macOS, `ctrl+s` on Linux and Windows. `Go Back` and `Get App Version` raise `E0105` on a desktop.
734
735 **Reference:** [appium-xa11y-driver](https://www.npmjs.com/package/appium-xa11y-driver)
