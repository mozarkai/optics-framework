183Optics runs desktop apps on macOS, Linux and Windows through Appium and `appium-xa11y-driver`. Run Appium on the machine that shows the app (see [Configuration](../configuration.md#driver-sources)).

201 app: com.apple.TextEdit
202 elements_sources:
203 - appium_find_element:
