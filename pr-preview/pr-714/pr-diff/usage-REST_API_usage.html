135## Desktop apps
136
137Start a session with the desktop, `automationName: Xa11y` and the app. The server launches the app. Run Appium with `appium-xa11y-driver` on the machine that shows the app.
138
139```bash
140SESSION=$(curl -sf -X POST "http://localhost:8000/v1/sessions/start" \
141 -H "Content-Type: application/json" \
142 -d '{"driver_sources": [{"appium": {"enabled": true, "url": "http://127.0.0.1:4723", "capabilities": {"platformName": "Mac", "automationName": "Xa11y", "app": "com.apple.TextEdit"}}}],
143 "elements_sources": ["appium_find_element", "appium_page_source", "appium_screenshot"]}' \
144 | python3 -c 'import json, sys; print(json.load(sys.stdin)["session_id"])')
145
146curl -sf -X POST "http://localhost:8000/v1/sessions/$SESSION/action" \
147 -H "Content-Type: application/json" \
148 -d '{"mode": "keyword", "keyword": "Enter Text", "params": ["//text_area", "Hello from Optics"]}'
149
150curl -sf "http://localhost:8000/v1/sessions/$SESSION/elements"
151
152curl -sf -X DELETE "http://localhost:8000/v1/sessions/$SESSION/stop"
