n467`Get Text` doesn't store its result automatically, so capture the returned text and compare it directly:n472### Assert Text
468473
nn474Waits until the text of an element equals the expected text, and fails the step if it does not. For a text field (`input` or `textarea`) on the web, it compares the field's current value. Spaces at the start and end are ignored on both sides.
475
476If the element is not found, the step fails with an element-not-found error, so the next value of a `${name}` element is tried. If the element shows a different text at the timeout, the step fails and the error gives the text that the element shows.
477
478The element must be in the UI tree. An element found only by OCR or image fails the step at once.
479
480An expected value with the `@:` prefix is compared without the prefix, and the error shows `****` in place of both texts.
